# 📋 오늘의 할 일 관리 서비스 (To-Do List)

> **LocalStorage와 구글 로그인 연동을 갖춘 미려하고 직관적인 웹 기반 To-Do List 애플리케이션입니다.**  
> 사용자 친화적인 UI/UX와 실시간 검색, 스마트 마감일 배지, 중요도 관리 등 완성도 높은 일정 관리 기능을 제공합니다.

---

## 🌟 주요 기능 (Key Features)

### 1. 직관적인 할 일(Task) 등록 및 관리
* **쉬운 등록**: 할 일 내용과 마감일을 지정하여 간편하게 등록할 수 있습니다.
* **키보드 단축키**: 입력 창에서 `Enter` 키를 눌러 신속하게 할 일을 추가할 수 있습니다.
* **완료 처리**: 체크 버튼 클릭 한 번으로 할 일을 완료 처리할 수 있으며, 완료된 작업은 시각적 불투명도 조절과 취소선 처리가 적용됩니다.

### 2. 중요 작업 지정 및 최상단 고정 (Starring)
* 할 일 목록에서 별표(★) 버튼을 클릭하여 중요 작업을 표시할 수 있습니다.
* 중요로 지정된 작업은 필터링 상태와 무관하게 **목록의 최상단에 정렬**되어 우선적으로 확인할 수 있습니다.

### 3. 스마트 디데이 배지 (D-Day Badges)
마감일에 따라 다이내믹하게 상태 배지가 변경되어 남은 시간을 한눈에 직관적으로 인지할 수 있습니다.
* 🚨 **기한 지남 X일** (적색 배지): 마감 기한이 지난 작업 표시
* ⚠️ **오늘 마감** (황색 배지): 오늘 완료해야 하는 작업 표시
* 📅 **내일 마감** / **마감 M/D**: 향후 마감 예정일 표시

### 4. 실시간 검색 및 필터링
* **실시간 키워드 검색**: 입력하는 즉시 작업 내용을 검색하여 필터링합니다.
* **상태별 필터**: 전체 작업 / 미완료 작업 / 완료 작업을 탭 형식으로 즉시 전환하여 볼 수 있습니다.
* **일괄 삭제**: 완료된 작업들만 한 번에 정리할 수 있는 '완료된 작업 삭제' 기능을 제공합니다.

### 5. 완벽한 테마 지원 및 설정 유지
* **다크 모드 & 라이트 모드**: 부드러운 애니메이션 전환 효과가 적용된 다크 테마를 제공합니다.
* **브라우저 저장소 연동**: 할 일 목록, 테마 설정(다크/라이트), 로그인 정보가 브라우저의 `LocalStorage`에 안전하게 보관되어 페이지를 새로고침하거나 브라우저를 종료한 뒤 다시 접속해도 데이터가 그대로 유지됩니다.

### 6. 구글 계정 간편 로그인 연동 (Google Sign-In)
* Google Identity Services Client SDK를 탑재하여 구글 계정으로 손쉽게 로그인할 수 있습니다.
* 로그인 시 구글 프로필 사진(아바타)과 사용자 이름이 표시되는 개인화 영역이 노출됩니다.

---

## 🛠 기술 스택 (Tech Stack)

* **Language**: Vanilla HTML5, Vanilla CSS3, JavaScript (ES6+)
* **API & SDK**: Google Identity Services Client SDK (GSI client)
* **Storage**: Web Storage API (LocalStorage)
* **Fonts**: System-default Sans-serif Font Stack (`-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `sans-serif`)

---

## 📁 디렉토리 구조 (Directory Structure)

```text
TO-DO/
├── index.html       # 메인 애플리케이션 (HTML 구조, CSS 스타일, JS 로직 통합)
└── README.md        # 프로젝트 안내 문서 (본 파일)
```

* **index.html**: 단일 파일 구조로 설계되어 코드의 응집도를 높이고 배포 및 실행의 편의성을 극대화하였습니다.
  * **CSS Custom Properties (Variables)** 를 사용해 라이트/다크 모드 색상 체계를 완벽히 분리하고, Glassmorphism 스타일과 매끄러운 트랜지션을 구현했습니다.
  * **ES6+ JS** 로직으로 LocalStorage 제어, JWT 토큰 파싱, 실시간 정렬 및 필터링 렌더 시스템을 구현했습니다.

## 🚀 시작하기 및 실행 방법 (Getting Started)

본 프로젝트는 순수 웹 표준 기술로만 빌드되었으므로 별도의 빌드 도구나 Node.js 설치가 필요하지 않습니다.

1. **저장소 클론 또는 다운로드**
2. **브라우저로 실행**:
   * `index.html` 파일을 더블 클릭하여 크롬(Chrome), 사파리(Safari), 엣지(Edge) 등의 웹 브라우저에서 바로 열 수 있습니다.
   * 또는 VS Code의 `Live Server` 확장 프로그램 등을 사용하여 로컬 개발 서버 환경(`http://localhost:5500`)에서 구동하면 구글 로그인 기능 등을 온전히 테스트해보실 수 있습니다.

## 🎨 UI/UX 디자인 주요 특징

* **모던 그린 팔레트**: 시각적 피로가 적고 차분한 느낌을 주는 프리미엄 파스텔 그린 테마를 기본으로 사용합니다.
* **부드러운 애니메이션**: 할 일을 등록하거나 상태를 변경할 때, 테마를 전환할 때 부드러운 `@keyframes` 애니메이션과 `transition` 효과를 부여하여 우수한 사용감을 제공합니다.
* **반응형 웹 디자인**: 미디어 쿼리(`@media`)를 최적화하여 데스크톱 대화면부터 태블릿, 모바일 기기 디스플레이 규격까지 흐트러짐 없는 최적의 화면 레이아웃을 제공합니다.
